# Rascunhos pessoais

Arquivos de trabalho temporários autorizados. Ao concluir, mover o resultado para o destino definitivo adequado, preservando originais e evitando cópias sensíveis desnecessárias.

Não há confirmação de exclusão automática após sete dias ou de limpeza semanal. Não confiar nessa retenção para proteger dados. Limpeza é operação destrutiva: definir escopo/retenção e obter autorização antes de implantar ou executar.

Estado das automações: `/srv/hermes/config/cronjobs/README.md`. Para probes e temporários de ferramentas, usar o scratch indicado pelo ambiente, não esta pasta por padrão.
